# ZedgeHost Expenses Tracker

Android app (WebView + offline HTML/JS) for tracking ZedgeHost startup expenses.

- Add, edit and delete expenses (date, category, amount in PKR, note, recurring)
- Totals by category and by month, data saved on the phone (localStorage, offline)
- Pre-filled: Meta Ads Nov 2026 and Server Rs 850/month recurring

Build: `./build.sh` (needs Android SDK 34, aapt2, d8, apksigner — see build.sh)
